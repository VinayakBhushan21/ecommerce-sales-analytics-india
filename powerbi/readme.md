# Power BI Dashboard

   `ecommerce_dashboard.pbix` — connects to the `analytics_project` MySQL database.

   ## Measures included
   - Total Revenue, Total Profit, Profit Margin %
   - Total Orders, Total Returns, Return Rate %
   - Average Order Value, Cancelled Orders %

   ## To open
   Requires Power BI Desktop and a local MySQL server running the
   `analytics_project` database (see /sql folder for schema + data).
